# Actualización del roadmap — 10 de agosto de 2026

Fuente: [Microsoft 365 Roadmap](https://www.microsoft.com/es-es/microsoft-365/roadmap)

Esta es la primera carga de la base de conocimiento. Recoge los elementos del roadmap activos a fecha de hoy relacionados con Copilot, capacidades de IA (agentes, memoria, Copilot Studio, Copilot Chat, etc.) e integraciones de Microsoft 365, ordenados por producto.

## Microsoft Copilot (Microsoft 365)

- **Power BI integration** (ID 567891) — *En desarrollo*. Copilot razona sobre datos empresariales de Power BI y devuelve respuestas fundamentadas a partir de informes y modelos semánticos mediante lenguaje natural. Preview: junio 2026. GA: agosto 2026.
- **New Rich Answer Cards** (ID 567007) — *En desarrollo*. Tarjetas de respuesta enriquecidas (clima, deportes, finanzas, imágenes, vídeo, lugares, noticias) para usuarios Entra y MSA. Disponibilidad: agosto 2026.
- **Workforce Insights Agent** (ID 515145) — *En desarrollo*. Agente que transforma datos complejos de plantilla en insights accionables sobre estructura organizativa, habilidades y patrones de trabajo. Disponibilidad: septiembre 2026.
- **Use Agent 365 agents within Copilot Chat** (ID 567670) — *En desarrollo*. Los agentes publicados en Agent 365 que implementan el protocolo Agent2Agent funcionan como agentes conectados dentro de Copilot Chat. Disponibilidad: agosto 2026.
- **Copilot memory in Researcher** (ID 562996) — *En desarrollo*. La memoria de Copilot aporta contexto de interacciones pasadas para fundamentar mejor los insights y personalizar resultados, reduciendo la configuración manual. Disponibilidad: noviembre 2026.
- **Session and Response Sharing** (ID 562353) — *En desarrollo*. Permite compartir sesiones de chat completas o respuestas individuales mediante enlace en modo solo lectura; el destinatario puede continuar en su propio chat de Copilot. Disponibilidad: agosto 2026.

## Microsoft Copilot Studio

- **SQL server Support** (ID 568930) — *En desarrollo*. Nueva fuente de conocimiento Azure SQL que amplía la integración de datos empresariales para construir agentes. Preview: septiembre 2026. GA: por confirmar.
- **Agent Readiness** (ID 568762) — *En desarrollo*. Comprobación de estado en tiempo real que muestra problemas bloqueantes antes de publicar un agente, con capacidades restringidas marcadas en gris. Disponibilidad: septiembre 2026.
- **Share Autonomous Agents (Run-Only)** (ID 567894) — *En desarrollo*. Permite a los creadores compartir agentes de forma segura en modo "solo ejecución", sin permisos de edición ni requisitos de propiedad. Preview: agosto 2026. GA: enero 2027.
- **Enable express mode for flows** (ID 566999) — *En desarrollo*. El modo exprés acelera notablemente los tiempos de ejecución de flujos invocados por agentes/apps, reduciendo fallos y timeouts. Preview: noviembre 2025. GA: noviembre 2026.

## Microsoft Teams

- **Intelligent call recaps in Queues app** (ID 569017) — *En desarrollo*. Resúmenes generados por IA, puntos clave de la conversación y acciones de seguimiento para llamadas grabadas en la app de Colas, accesibles desde la pestaña Recap. Disponibilidad: septiembre 2026.
- **Use Copilot Chat after a call in Queues app** (ID 568933) — *En desarrollo*. Tras finalizar una llamada grabada, permite usar Copilot Chat en la app de Colas para ponerse al día rápidamente sin revisar la transcripción manualmente. Disponibilidad: septiembre 2026.

## Outlook

- **Language support for Summarize in Classic Outlook** (ID 569023) — *En desarrollo*. Permite elegir un idioma distinto para ver los resúmenes de Copilot cuando el idioma del contenido no coincide con el de Outlook. Preview: septiembre 2026. GA: octubre 2026.
- **New Copilot entry point in Classic Outlook** (ID 567007) — *En desarrollo*. Punto de entrada consistente de Copilot situado sobre el contexto de trabajo, que muestra acciones relevantes conectadas con el resto de Microsoft 365. Disponibilidad: agosto 2026.

## SharePoint

- **Enterprise store plugins in Copilot in SharePoint** (ID 567669) — *En desarrollo*. Copilot en SharePoint admite plugins de la tienda empresarial, agrupando skills y servidores MCP para ampliar capacidades. Preview: agosto 2026. GA: diciembre 2026.
- **Personal Skills in Copilot in SharePoint** (ID 567668) — *En desarrollo*. Permite crear skills personales en Copilot que se mantienen entre sitios de SharePoint y OneDrive, guardadas como markdown en OneDrive. Preview: agosto 2026. GA: diciembre 2026.

## Microsoft Viva

- **Copilot Dashboard - Targeted Audience Surveys** (ID 568072) — *En desarrollo*. Permite lanzar encuestas Copilot Pulse dirigidas a usuarios con licencia/activos, con actualización automática de audiencia a partir de datos de Insights. Preview: agosto 2026. GA: septiembre 2026.
- **Viva Glint - Copilot admin configuration assistance** (ID 567320) — *En desarrollo*. Asistente conversacional que responde preguntas de configuración con guía paso a paso y enlaces directos para administradores. Disponibilidad: septiembre 2026.
- **Copilot Analytics - Agent 365 dashboard** (ID 567893) — *En desarrollo*. Los managers acceden a datos de Agent 365 a través del Agent Dashboard en Copilot Analytics, con visibilidad de actividad entre agentes. Disponibilidad: agosto 2026.
- **Copilot Analytics - Agent 365 Dashboard in Insights** (ID 567667) — *En desarrollo*. Los líderes entienden la actividad de todos los agentes registrados en Agent 365 mediante el Agent Dashboard, con acceso a datos históricos. Preview: julio 2026.

## Microsoft Purview

- **Data Loss Prevention for non-Microsoft connected apps** (ID 568075) — *En desarrollo*. Extiende DLP y etiquetado automático a Google Workspace, Box, Dropbox, Salesforce, ServiceNow, AWS y Cisco Webex. Preview: agosto 2026. GA: septiembre 2026.
- **Insider Risk Management - DS Triage Agent** (ID 567472) — *En desarrollo*. Resúmenes del agente en Microsoft Defender que aportan información clave de triaje para alertas de IRM sin salir del flujo de trabajo de Defender. Preview: agosto 2026. GA: diciembre 2026.

## Planner

- **AI-generated Status Reports in Planner Agent** (ID 567887) — *En desarrollo*. La IA transforma los datos del plan en informes de estado listos para stakeholders, con progreso, riesgos y próximos pasos personalizables. Preview: agosto 2026. GA: septiembre 2026.
- **Planner Agent chat in Basic Plans** (ID 567671) — *En desarrollo*. Chat integrado del agente de Planner con preguntas en lenguaje natural, descubrimiento inteligente de tareas y gestión de tareas dentro del plan. Disponibilidad: agosto 2026.

## OneNote

- **Multimodal capture in Copilot Notebooks (Android)** (ID 567895) — *En desarrollo*. Permite transcribir audio, capturar imágenes y escribir notas en una misma sesión; Copilot genera una página estructurada con insights. Preview: agosto 2026. GA: septiembre 2026.

## Microsoft 365 app

- **New Copilot Notebooks design (Android)** (ID 566704) — *En desarrollo*. Copilot Notebooks permite organizar chats y creaciones en espacios de trabajo de IA persistentes, con contexto acumulado. Disponibilidad: agosto 2026.
