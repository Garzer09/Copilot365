## Metodología

Los datos se obtienen de la API pública del Microsoft 365 Roadmap (`microsoft.com/releasecommunications/api/v1/m365`), filtrando por elementos cuyo título, descripción o etiquetas mencionan "Copilot", "agent" o "artificial intelligence", y acotando a los modificados en la ventana cubierta indicada arriba. Cada actualización posterior de este documento debe:

1. Volver a consultar la API del roadmap.
2. Filtrar por `modified` posterior a la fecha de la última actualización registrada aquí.
3. Añadir/mover los ítems relevantes a las secciones correspondientes (Launched / Rolling out / In development / Cancelled).
4. Actualizar la cabecera con la nueva fecha y ventana cubierta.
