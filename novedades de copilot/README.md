# Novedades de Microsoft 365 Copilot

Base de conocimiento con el seguimiento de las novedades del [Microsoft 365 Roadmap](https://www.microsoft.com/es-es/microsoft-365/roadmap) relevantes para Copilot, funcionalidades de IA e integraciones de Microsoft 365.

## Cómo está organizado

- Cada actualización se registra en un fichero `AAAA-MM-DD-actualizacion-roadmap.md` con la fecha en la que se revisó el roadmap.
- Cada fichero agrupa los elementos por producto (Microsoft Copilot, Copilot Studio, Teams, Outlook, SharePoint, Viva, Purview, Planner, OneNote, etc.) e indica: ID del roadmap, estado, descripción, fechas de disponibilidad (Preview/GA) y fecha de última modificación en el roadmap.
- Solo se incluyen elementos relacionados con Copilot, capacidades de IA (agentes, Copilot Studio, Copilot Chat, memoria, índice semántico, etc.) o integraciones de Microsoft 365 con esas capacidades.
