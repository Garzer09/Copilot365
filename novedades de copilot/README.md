# Novedades de Copilot

Base de conocimiento con las novedades del [Microsoft 365 Roadmap](https://www.microsoft.com/es-es/microsoft-365/roadmap) relevantes para Copilot, capacidades de IA e integración de Microsoft 365.

Los datos se obtienen directamente de la API pública del roadmap (`https://www.microsoft.com/releasecommunications/api/v1/m365`), filtrando los elementos relacionados con Copilot, agentes e IA.

## Cómo está organizado

- Cada actualización se guarda en un archivo con formato `AAAA-MM-DD-actualizacion-roadmap.md`, con las novedades detectadas desde la última revisión.
- `estado-sincronizacion.json` guarda la fecha y el ID más reciente ya procesados, para que las siguientes ejecuciones solo añadan lo nuevo.
