## Capa de inteligencia: Work IQ

**Work IQ** es la capa de inteligencia de Microsoft 365 Copilot que proporciona comprensión semántica de todo lo que ocurre en la empresa. Consolida señales de correo electrónico, calendario, reuniones, chats, archivos y sistemas conectados para potenciar tanto a Copilot como a los agentes con conocimiento contextual organizativo.

Las Work IQ APIs (en preview desde junio 2025) permiten acceso programático a esta capa mediante:
- **REST**: integración estándar para desarrolladores
- **A2A (Agent-to-Agent)**: comunicación entre agentes
- **MCP (Model Context Protocol)**: protocolo abierto para conectar modelos de IA con herramientas y datos
