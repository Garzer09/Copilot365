# Novedades de Microsoft 365 Copilot — Roadmap

**Fuente:** [Microsoft 365 Roadmap](https://www.microsoft.com/es-es/microsoft-365/roadmap)
**Última revisión:** 2026-08-24

Este documento resume, a partir del roadmap oficial de Microsoft 365, las funcionalidades relacionadas con **Copilot, capacidades de IA e integraciones de Microsoft 365** que están en despliegue o en desarrollo. Se actualiza periódicamente; ver el historial al final del documento.

## En despliegue (Rolling out)

Funcionalidades que ya se están entregando activamente a los usuarios.

| Funcionalidad | Producto | Última actualización | Descripción |
|---|---|---|---|
| Viva Glint — Asistencia de Copilot para configuración de administradores | Microsoft Viva | 2026-08-18 | Asistente conversacional embebido que ayuda a los administradores con preguntas de configuración y guía paso a paso dentro de Viva Glint. |

## Notas

- El roadmap de Microsoft 365 cambia constantemente; las fechas de disponibilidad general (GA) no están confirmadas para los elementos "En desarrollo" hasta que Microsoft las publique.
- No se han identificado, en esta revisión, elementos con estado "Launched" (disponibilidad general) para las etiquetas Microsoft Copilot (Microsoft 365) / Microsoft Copilot Studio dentro de la ventana de los últimos 60 días.
- Este documento es un resumen curado, no una copia exhaustiva del roadmap. Para el detalle completo y filtros adicionales, consultar la fuente oficial.
