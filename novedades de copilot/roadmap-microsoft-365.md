# Novedades del Roadmap de Microsoft 365 – Copilot & IA

> Fuente oficial: [Microsoft 365 Roadmap](https://www.microsoft.com/es-es/microsoft-365/roadmap)
> Última revisión: **6 de julio de 2026**

Este documento resume las funcionalidades del roadmap de Microsoft 365 relacionadas con **Copilot, capacidades de IA e integraciones** relevantes para Copilot365. Se actualiza cada vez que se revisa el roadmap oficial para dejar constancia de qué hay disponible, en despliegue o próximo a llegar.

## Disponible con carácter general (GA)

| Función | Producto | Fecha | Descripción |
|---|---|---|---|
| **Copilot Cowork** | Microsoft 365 Copilot | 16 jun 2026 | IA "enterprise-ready" para trabajo multi-paso de larga duración: automatiza tareas a través de Microsoft 365 y apps conectadas, con controles de seguridad integrados. |
| **Work IQ API** | Microsoft 365 Copilot | 16 jun 2026 | Acceso programático a la capa de inteligencia laboral; permite que los agentes entiendan de forma semántica datos y flujos de trabajo de la organización. |
| **GPT-5.5 Instant** | Microsoft 365 Copilot | 7 may 2026 | Modelo de baja latencia optimizado para preguntas de trabajo habituales, entradas con imágenes y tareas STEM en tiempo real. |
| **Claude Opus 4.7 / 4.8** | Microsoft 365 Copilot | — | Integración de modelos de Anthropic para trabajo complejo multi-paso, con mejor seguimiento de instrucciones, selección de herramientas y comprensión visual. |
| **Multi-model Researcher** | Microsoft 365 Copilot | — | Compara respuestas de Claude y GPT en paralelo, o refina resultados de GPT usando Claude, para decisiones mejor informadas. |
| **Copilot en Excel: capacidades de Finanzas** | Excel | 24 jun 2026 | Funciones orientadas a finanzas: aplicar estándares propios, usar fuentes de datos financieros de confianza y mantener control sobre los cambios analíticos. |
| **Capacidades agénticas de Copilot** | Word, Excel, PowerPoint | — | Copilot puede planificar, ejecutar y refinar tareas complejas multi-paso dentro de las apps de productividad (creación de documentos, análisis de datos, presentaciones). |
| **Microsoft 365 E7 + Agent 365** | Licenciamiento | — | Licencia unificada que combina Microsoft 365 E5, Copilot y Agent 365 con controles de gobierno y despliegue. |
| **Agentes de voz en tiempo real (Copilot Studio)** | Dynamics 365 Contact Center | — | Interacciones de voz natural (speech-to-speech) con clientes. |

| Función | Producto | Estado | Descripción |
|---|---|---|---|

| **Grounding en Microsoft 365** | Microsoft 365 Copilot | Preview público en junio 2026 → GA en julio 2026 | Mejora la base de respuestas de Copilot ampliando el contexto tomado de contenido y datos propios de Microsoft 365. |
| **Correos de Outlook como referencia en Copilot Notebooks** | Copilot Notebooks | Rolling out en julio 2026 | Permite añadir correos de Outlook como referencia para fundamentar a Copilot en conversaciones, decisiones y contexto reales del trabajo. |
| **Copilot Cowork: navegación web y nuevos modelos** | Microsoft 365 Copilot | En desarrollo | Añade automatización de navegador web e introduce "Cowork 1", un modelo optimizado en coste para tareas del día a día. |
| **Microsoft Scout** | Microsoft 365 Copilot | En desarrollo (Frontier) | Agente personal que actúa de forma proactiva en Microsoft 365, con app de escritorio complementaria para automatizar archivos locales y tareas web. |

| **Agent Mode** | Word, Excel, PowerPoint | En desarrollo | Generación end-to-end de documentos, hojas de cálculo y presentaciones directamente en las apps nativas. |

| **Funciones agénticas en Outlook** | Outlook | En desarrollo | Gestión de correo y calendario asistida por IA: programación y seguimientos automáticos. |
| **App Builder para Copilot** | Microsoft 365 Copilot | En desarrollo | Creación rápida de apps a partir de una descripción de intención, sin necesidad de conocimientos técnicos avanzados. |

## Cambio importante de proceso (julio 2026)

Desde el **2 de julio de 2026**, Microsoft publica las novedades de **Copilot Studio, Sales Agent, Finance Agent y Service Agent** directamente en el **Microsoft 365 Roadmap**, en lugar del antiguo *Release Planner*, que deja de ser la fuente de información para esos productos. A partir de ahora hay que consultar el roadmap unificado también para el seguimiento de estos agentes.

## Relevancia para Copilot365

- **Grounding en M365** y **correos de Outlook en Copilot Notebooks** (ambos GA en julio 2026) son directamente aplicables a cualquier integración que Copilot365 haga con datos de Microsoft 365: mejoran la calidad de las respuestas contextualizadas.
- **Work IQ API** y los **conectores federados de Copilot** son relevantes si Copilot365 necesita exponer o consumir datos organizacionales de forma programática.
- **Vision en Microsoft 365 Copilot** abre la puerta a experiencias que combinan contexto visual (pantalla/cámara) con datos de trabajo.
- El cambio de proceso del roadmap (Copilot Studio/agentes ahora en M365 Roadmap) afecta a cómo se debe monitorizar este documento en el futuro: una sola fuente en lugar de dos.
